# HTB — Final report

## When to use this skill
The flags are captured. Goal: turn `notes.md` / `creds.txt` / `techniques.txt`
into a readable report that tells the attack path and cements the learning.
It complements the ATT&CK Navigator layer (the "what") with the narrative
(the "how" and the "why").

## Report structure (Markdown)

```markdown
# Report — <Box> (<IP>)
- **Date**: <date>   **Difficulty**: <Easy/Medium/Hard>   **OS**: <Linux/Windows>
- **Operator**: <you>   **Scope**: Hack The Box (authorized target)

## 1. Executive summary
3-5 line summary: entry point, privesc vector, time spent.

## 2. Reconnaissance
Key ports/services (table). What drove the next steps.

## 3. Attack path (step by step)
For each step: action → result → **ATT&CK technique (T####)** → evidence.
| # | Step | Key command | Result | ATT&CK |
|---|------|-------------|--------|--------|
| 1 | Scan | nmap -p- | 80,445 open | T1046 |
| 2 | Web  | ffuf | /admin found | T1595.002 |
| … |      |      |          |        |

## 4. Initial access (foothold)
How the first shell was obtained. Evidence: `id` / `whoami`.

## 5. Privilege escalation
Exact vector, why it worked. Evidence: root `id` / `whoami /priv`.

## 6. Evidence (flags)
- user.txt: `<hash>`
- root.txt: `<hash>`

## 7. Remediation (defense)
For each exploited weakness: concrete fix (patch, config, least privilege).

## 8. Appendices
- ATT&CK coverage: see `<box>.json` (ATT&CK Navigator).
- Credentials: see creds.txt (do not distribute outside the authorized scope).
```

## Procedure
1. Re-read `notes.md` and fill in the sections in the order of the actual path.
2. Record each step in the §3 table with its **T####** identifier
   (same IDs as `techniques.txt` → consistency with the Navigator layer).
3. Insert minimal evidence (`id` output, flag hash), no useless screenshots.
4. Write the **remediation**: this is what sets a report apart from a plain write-up.
5. Generate the ATT&CK layer and cite it in the appendix:
   ```bash
   python3 skills/htb-workflow/gen-navigator-layer.py -n "<Box>" -f techniques.txt -o <box>.json
   ```

## Converting to PDF
```bash
# via pandoc (install if needed: apt install pandoc wkhtmltopdf)
pandoc report.md -o report.pdf --pdf-engine=wkhtmltopdf -V geometry:margin=2cm
# or as standalone HTML
pandoc report.md -o report.html -s --toc
```

## Reflexes
- A good report is **reproducible**: a third party should be able to replay the path.
- Always include remediation: offense without defense is incomplete.
- Do not distribute `creds.txt` or the report outside the authorized scope.
- Keep the technique numbering aligned with the Navigator layer.
